Ejercicio 3
Codificar
Implementar una pila con arreglo
Usando un arreglo de enteros de tamaño 5, escribí los métodos push(int x) y pop(). Considerá los casos de pila llena y pila vacía. 
int[] pila = new int[5];
int tope = -1;

void push(int x) {
    if (tope == pila.length - 1)
        System.out.println("Pila llena");
    else
        pila[++tope] = x;
}

int pop() {
    if (tope == -1) {
        System.out.println("Pila vacia");
        return -1;
    }
    return pila[tope--];
}

    int dato;
    Nodo siguiente;
    Nodo(int x) {

        siguiente = null;
    }

    Nodo cabeza = null;

Lista enlazada vs. Arreglo
Analizá las siguientes situaciones e indicá cuál estructura es más adecuada y por qué:

a) Almacenar las notas de 30 alumnos cuya cantidad no cambia durante el año.
b) Gestionar una lista de tareas donde se agregan y eliminan ítems constantemente.
c) Acceder directamente al elemento en la posición 15 de una colección de 100 elementos.
d) Insertar un elemento al inicio de una colección de 1000 elementos frecuentemente.
a) Arreglo — tamaño fijo conocido, acceso directo eficiente.
b) Lista enlazada — inserciones y eliminaciones O(1) al inicio/fin.
c) Arreglo — acceso por índice O(1); lista necesita recorrer O(n).
d) Lista enlazada — inserción al inicio O(1); en arreglo requiere desplazar 1000 elementos O(n).
