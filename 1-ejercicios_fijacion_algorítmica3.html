Ejercicio 1
Traza
¿Qué muestra este algoritmo?
Seguí la ejecución paso a paso e indicá qué se imprime en cada iteración. 
int[] notas = {7, 4, 9, 6, 3, 8};
int suma = 0;
for (int i = 0; i < notas.length; i++) {

Ejercicio 2
Codificar
Implementar una pila con arreglo
Usando un arreglo de enteros de tamaño 5, escribí los métodos push(int x) y pop(). Considerá los casos de pila llena y pila vacía.
int[] pila = new int[5];
int tope = -1;

void push(int x) {
    if (tope == pila.length - 1)
        System.out.println("Pila llena");
    else
        pila[++tope] = x;
}

int pop() {
    if (tope == -1) {
        System.out.println("Pila vacia");
        return -1;
    }
    return pila[tope--];
}

Ejercicio 1
Conceptual
Tipos de listas y sus características
Uní cada tipo de lista con su descripción correcta:

Tipos: Contigua · Enlazada simple · Circular · Doblemente encadenada · Doblemente encadenada circular

Descripciones:
a) Sus elementos ocupan posiciones de memoria adyacentes; se implementa con arreglos.
b) El último nodo apunta al primer nodo de la lista.
c) Cada nodo tiene dos punteros: siguiente y anterior.
d) El puntero anterior del primer nodo apunta al último, y el siguiente del último apunta al primero.
e) Cada nodo tiene un campo dato y un puntero al nodo sucesor; el último apunta a null.
a) Contigua
b) Circular
c) Doblemente encadenada
d) Doblemente encadenada circular
e) Enlazada simple
